# 🎉 欢迎使用本地代码编译器

## 📦 新版本特性

### ✅ 已解决的问题
1. **语言切换代码保存** - 每种语言的代码独立保存，切换时自动加载
2. **无需单独服务器** - 桌面应用版一键启动
3. **Network Error** - 不再依赖网络，完全本地运行

## 🚀 快速开始（三步走）

### 第一步：安装依赖
双击运行 **`安装依赖.bat`**

### 第二步：启动应用
双击运行 **`启动应用.bat`**

### 第三步：开始编程
- 选择编程语言
- 编写代码
- 点击"运行代码"

## 📝 使用说明

### 代码自动保存
- ✅ 每种语言的代码独立保存
- ✅ 切换语言时自动保存当前代码
- ✅ 再次切换回该语言时自动加载

### 示例
1. 选择 Python，编写代码：`print("Hello")`
2. 切换到 C++，编写代码：`cout << "World";`
3. 切换回 Python，之前的代码 `print("Hello")` 还在！

## 🎯 两种运行模式

### 模式 1：桌面应用（推荐）
```
启动应用.bat → 自动打开应用窗口
```
- ✅ 无需浏览器
- ✅ 独立窗口
- ✅ 菜单快捷键

### 模式 2：浏览器访问
```
start-server.bat → 浏览器访问 http://localhost:3000
```
- ✅ 使用浏览器
- ✅ 多标签页

## 🛠️ 安装编译器

### Python 3（最简单）
1. 访问 https://www.python.org/downloads/
2. 下载并安装
3. **重要**：勾选 "Add Python to PATH"

### 其他语言
查看 README.md 中的详细说明

## ⌨️ 快捷键

- `Ctrl + Enter` - 运行代码
- `Ctrl + S` - 下载代码
- `Ctrl + N` - 清空编辑器
- `F11` - 全屏

## ❓ 常见问题

### Q: 启动失败怎么办？
A: 
1. 确保已安装 Node.js
2. 运行 "安装依赖.bat"
3. 重新启动

### Q: 编译器未找到？
A: 
1. 安装对应语言的编译器
2. 确保添加到 PATH
3. 重启应用

### Q: 代码会丢失吗？
A: 不会！每种语言的代码独立保存，切换语言时自动保存和加载。
