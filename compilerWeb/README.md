# 在线代码编译器

一个现代化的多语言在线代码编译器，支持 C、C++、Python、Java、JavaScript、Go、Rust、C# 等多种编程语言。

## ✨ 核心特性

- **多 API 支持**：Piston API（主）+ Wandbox（备用），自动切换
- **代码保存**：每种语言的代码独立保存，切换语言自动加载
- **多语言支持**：支持 8 种主流编程语言
- **现代化 UI**：采用现代化设计风格，支持深色/浅色主题切换
- **智能代码编辑器**：集成 Monaco Editor（VS Code 同款编辑器）
- **友好的错误提示**：智能格式化错误信息，易于理解
- **响应式设计**：完美适配手机、平板和电脑

## 🚀 快速开始

### 方式 1：直接打开（推荐）

直接在浏览器中打开 `index.html` 文件即可使用。

### 方式 2：使用本地服务器

```bash
# 使用 Python
python -m http.server 8080

# 或使用 Node.js
npx http-server -p 8080

# 然后访问 http://localhost:8080
```

### 方式 3：双击启动脚本

双击运行 `启动.bat`，然后在浏览器中访问 http://localhost:8080

## 📖 使用说明

1. **选择语言**：从下拉菜单中选择你想要使用的编程语言
2. **编写代码**：在编辑器中编写你的代码
3. **输入数据**（可选）：在"输入"标签页中输入程序的输入数据
4. **运行代码**：点击"运行代码"按钮或按 `Ctrl + Enter`
5. **查看结果**：在"输出"标签页查看运行结果

### 代码自动保存

- ✅ 每种语言的代码独立保存
- ✅ 切换语言时自动保存当前代码
- ✅ 再次切换回该语言时自动加载

## 🔧 API 服务说明

本编译器使用以下 API 服务（按优先级排序）：

### 1. Piston API（主服务）

- 开源的代码执行引擎
- 稳定可靠，响应快速
- 支持多种编程语言
- 无需 API Key

### 2. Wandbox（备用服务）

- 成熟的在线编译器服务
- 支持多种语言版本
- 当 Piston API 不可用时自动切换

**自动切换机制**：
- 优先使用 Piston API
- 如果 Piston API 失败，自动切换到 Wandbox
- 确保代码编译的可靠性

## ⌨️ 快捷键

- `Ctrl + Enter` - 运行代码
- `Ctrl + S` - 下载代码到本地
- `Ctrl + /` - 注释/取消注释

## 🐛 常见问题

### 1. Network Error / 网络错误

**原因**：网络连接问题或 API 服务暂时不可用

**解决方案**：
- 检查网络连接
- 稍后重试
- 系统会自动尝试备用 API

### 2. 编译错误

**原因**：代码语法错误或逻辑错误

**解决方案**：
- 查看输出窗口中的错误信息
- 检查代码语法
- 确保使用正确的语言版本

### 3. 请求超时

**原因**：代码执行时间过长或网络延迟

**解决方案**：
- 优化代码，减少执行时间
- 检查网络连接
- 稍后重试

### 4. API 服务切换

**现象**：看到"正在使用 Piston API 编译和运行代码..."或"Wandbox 失败，尝试使用备用服务..."

**说明**：这是正常的自动切换行为，系统会自动选择可用的 API 服务。

### 5. 移动端显示问题

**解决方案**：
- 确保使用现代浏览器（Chrome、Safari、Firefox）
- 清除浏览器缓存
- 尝试横屏模式
