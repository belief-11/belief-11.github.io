使用帮助

快速开始

  1. 选择你想要使用的编程语言
  2. 在编辑器中编写你的代码
  3. 如果需要输入数据，在"输入"标签页中输入
  4. 点击"运行代码"按钮执行程序
  5. 在"输出"标签页查看运行结果

支持的语言

  • C++ - 使用 G++ 编译器
  • Python 3 - 最新稳定版本
  • Java - OpenJDK
  • JavaScript - Node.js 运行时
  • Go - 官方 Go 编译器

快捷键

  • Ctrl + Enter - 运行代码
  • Ctrl + S - 保存代码到本地
  • Ctrl + / - 注释/取消注释
